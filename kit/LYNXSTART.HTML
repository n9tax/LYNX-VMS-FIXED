Lynx 2.9.3 on OpenVMS

This is the default start page. It is a local file, so it always loads. As soon as you add a bookmark of your own, your bookmarks become your start page instead, and you will not see this page again.

Bookmarks

Your bookmark file is your own: SYS$LOGIN:lynx_bookmarks.html. Nobody else can see it, and you do not have to set anything up.

  • a — add the current page to your bookmarks
  • v — view your bookmarks
  • r — remove a bookmark, while viewing them

Lynx creates the file the first time you add a bookmark.

Getting around

  • g — go to a URL you type
  • Up / Down — move between links, Enter to follow
  • Left — back, Right — follow link
  • o — options, H — help, q — quit
  • / — search within the page

You can also start on any page directly: $ LYNX http://example.com/

No HTTPS

This build has no SSL, so https: URLs will not work. Plain http: does. If you need HTTPS, run an HTTP-to-HTTPS proxy on another machine and point Lynx at it:

$ DEFINE "https_proxy" "http://yourproxy.example:3128/"

For the system manager

The global configuration is Lynx_Dir:lynx.cfg. To change this start page for everyone, edit STARTFILE there. Any page you point it at must be readable by everyone (World:RE) or users will get Can't access startfile.
